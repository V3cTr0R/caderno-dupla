Caderno colaborativo de Git

Projeto colaborativo para praticar Git, GitHub, branches e resolução de conflitos.

O que é este projeto?

Este caderno reúne dicas básicas de Git utilizadas durante uma atividade prática de colaboração em dupla. O objetivo é registrar alterações, compartilhar o projeto no GitHub e compreender como conflitos de merge podem ser resolvidos.

Dicas de Git

  1. Dica 1 — Verifique o status antes de trabalhar: use git status para conferir a branch atual e identificar arquivos modificados, novos ou pendentes de commit. Autor: Aluno A
  2. Dica 2 — Atualize o repositório antes de enviar: execute git pull origin main antes de começar uma nova alteração ou antes de usar git push. Isso reduz a chance de trabalhar sobre uma versão desatualizada. Autor: Aluno B

Comandos utilizados

  • git status: mostra a situação atual do repositório.
  • git add .: prepara os arquivos alterados para o próximo commit.
  • git commit -m "mensagem": registra uma alteração no histórico local.
  • git pull origin main: baixa e integra atualizações da branch principal.
  • git push origin main: envia commits locais para o GitHub.
  • git checkout -b Versao0.2: cria e acessa uma branch de versão.

Fluxo de trabalho

Para reduzir conflitos durante o trabalho colaborativo, o fluxo recomendado é:

pull → editar → add → commit → push
